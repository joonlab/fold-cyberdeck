조용히 실패하는 UDP 함정 — 에러 없이 입력만 안 가던 세 가지
예외 메시지가 null
UI 스레드에서 보낸 UDP 가 NetworkOnMainThreadException 으로 죽는데, 로그엔 send: null 만 남았다. 영상은 오고 입력만 안 갔다.
람다가 한 번도 안 불림
콜백 람다가 같은 이름의 멤버 함수로 해석돼 입력 패킷이 한 번도 나가지 않았다. 컴파일도 경고도 없었다.
탭이 우클릭이 됨
주입한 ⌃ 플래그가 맥에 남아 이후 클릭이 전부 우클릭이 됐다. 듣기 전용 이벤트 탭으로 «도착한 것»을 보고 찾았다.
